# Changelog

## v0.1.2 — First public release

- Added **Possible matches**, a separate tab for punctuation, article, edition-label, and conservative typo variations.
- Kept exact duplicates and hidden entries in their own tabs.
- Retained Ctrl/Shift/Ctrl+A selection with batch Mark/Unmark and Yes/No confirmation previews.
- Preserved protections against hiding the last visible title copy or last visible installed copy.
- Added conservative sequel guards to prevent automatically suggesting obvious numbered sequels.
- Added release-file checksum checks, source privacy review, and public release documentation.
